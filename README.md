# 🧙 Immutable Roots

**Até onde sua magia pode levá-lo?**

**Immutable Roots** é um jogo de **plataforma 2D em pixel art**, no estilo *infinite runner*, que combina **ação, reflexos, memória e estratégia elemental**.

Controle um pequeno mago, desvie de obstáculos e enfrente dragões cada vez mais poderosos. Seu objetivo é simples: **sobreviver e chegar o mais longe possível!**

**Projeto desenvolvido para a Game Jam +.**

**Disponível para download em:** [Immutable Roots](https://thiagovtgame.itch.io/immutable-roots)

&nbsp;

## Como jogar 🔮

O mago pode **se movimentar para a esquerda e para a direita, saltar e realizar ataques mágicos**. Durante a jornada, ele precisa desviar dos obstáculos do cenário e enfrentar dragões utilizando quatro elementos: **Água, Terra, Ar e Fogo**.

Cada encontro exige atenção às sequências elementais apresentadas pelo dragão e rapidez para responder com os **counters corretos**.

### Ataques 🗡️​

Tanto o mago quanto os dragões possuem ataques. Quando o dragão **não estiver apresentando uma sequência de elementos**, o mago deve aproveitar para atacá-lo, preferencialmente utilizando o elemento correspondente à **fraqueza do inimigo**.

Enquanto causa dano ao dragão, o jogador também deve continuar desviando dos **obstáculos do mapa**.

### Defesas e counters 🛡️​

Quando uma sequência de elementos aparecer acima da cabeça do dragão, o jogador deverá responder com os **elementos que anulam cada ataque**, respeitando a ordem e as regras do dragão enfrentado.

O mago precisa concluir a sequência **antes que o tempo termine**. Se falhar, recebe o ataque do dragão e perde vida. Alguns dragões aplicam penalidades maiores.

### Relação entre elementos 📜

| Elemento do dragão | Counter do mago |
|---|---|
| 🔥 Fogo | 💧 Água |
| 💧 Água | 🌱 Terra |
| 🌱 Terra | 💨 Ar |
| 💨 Ar | 🔥 Fogo |

## Dragões e seus desafios

### 🔥 Dragão de Fogo

- **Desafio:** apresenta sequências menores de elementos, mas oferece **menos tempo** para o mago acertar os counters.
- **Fraqueza:** Água.

### 💧 Dragão de Água

- **Desafio:** a sequência de elementos desaparece após um tempo. O jogador deve **memorizá-la** e executar os counters de memória.
- **Fraqueza:** Terra.

### 🌱 Dragão de Terra

- **Desafio:** apresenta uma **sequência mais longa** e concede mais tempo para respondê-la. Porém, caso o mago falhe, **perde 2 corações**.
- **Fraqueza:** Ar.

### 💨 Dragão de Ar

- **Desafio:** a sequência de ataques é **invertida**: o jogador deve counterar os elementos **da direita para a esquerda**.
- **Fraqueza:** Fogo.

### 🐲 Dragão Ancestral

- **Desafio:** combina aleatoriamente as mecânicas dos dragões anteriores. O mago pode precisar memorizar a sequência, executá-la ao contrário ou lidar com sequências curtas ou longas.
- **Velocidade:** o mundo fica **10% mais rápido**.
- **Fraqueza:** não possui. Qualquer elemento pode causar dano, mas os ataques elementais **causam menos dano**.

### 👹 Dragão Demônio

- **Desafio:** reúne as mesmas características do Dragão Ancestral e adiciona uma mecânica de **roleta elemental**.
- **Velocidade:** o mundo fica **30% mais rápido**.
- **Elemento proibido:** a cada **3 rodadas**, um elemento se torna proibido. Se o jogador utilizar esse elemento, o mago recebe o **ataque correspondente do dragão**.
